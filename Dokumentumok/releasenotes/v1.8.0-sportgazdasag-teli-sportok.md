# v1.8.0 – Sportgazdaság és Téli sportok

2026-11-26

A Sportgazdaság a További rovatok között jelenik meg. A sport üzleti híreit gyűjti, például a szponzorációról, a közvetítési jogokról és az átigazolási díjakról. A Téli sportok a sportrovatokhoz került, többek között sí-, korcsolya-, biatlon- és jégkoronghírekkel. Egy cikk mindkét rovatba kerülhet. A feldolgozás a várakozó cikkek meglévő besorolását is kiegészíti.

Hat besorolási próba sikeres, köztük a kettős besorolás, valamint az időjárási, általános gazdasági és mérkőzéshírek kizárása az új rovatokból. A Python és JavaScript szintaxis-ellenőrzése, valamint a Git diff ellenőrzése sikeres.
