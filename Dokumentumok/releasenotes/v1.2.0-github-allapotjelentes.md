# v1.2.0 – GitHub Actions állapotjelentés

2026. november 24.

A napi 15:00-s és 21:00-s NANONews állapotjelentés GitHub Actionsben készül, és a napi Markdown-fájl megfelelő fejezetébe kerül. A jelentéshez nem kell ChatGPT, Gemini vagy új API-kulcs.

A 15:00-s történeti visszajátszás egyezett a mentett jelentés cikk- és készültségi adataival. A két fejezet külön mentését és az ismételt futás kezelését helyben ellenőriztük.
