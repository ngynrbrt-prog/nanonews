# NANONews v1.0.0 – Release notes folyamat

**Dátum** 2026-11-24

## Kérés

Minden NANONews-kéréshez készüljön verziózott Markdown release note a `Dokumentumok/releasenotes` mappában. A bejegyzés tartalmazza a kérést, a tesztelés állapotát és eredményét.

## Eredmény

Az [AGENTS.md](../../AGENTS.md) rögzíti a fájlnevet, a verzióléptetés szabályát, a kötelező tartalmat és a lezárás előtti ellenőrzést. Ez a folyamat első bejegyzése, ezért a kezdő verzió **v1.0.0**.

## Tesztelés

|---|---|---|
| Projektutasítás visszaolvasása a főágról és összevetése a mentett szöveggel | Elvégezve | Sikeres. A tartalom egyezik, és tartalmazza a könyvtárat, a verziózást és a teszteredmény rögzítését. |
