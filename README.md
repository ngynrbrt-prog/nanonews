# NANONews
Személyes, magyar nyelvű sporthír-összefoglaló. Statikus GitHub Pages, RSS-ből gyűjtött hírek, GitHub Actions ütemezéssel; külső fizetős API és adatbázis nélkül.
  
Források: Telex, HVG, Index, Nemzeti Sport. Kezdeti kulcsszavak: Arsenal, Manchester City, Bayern München, Manchester United, Como, Fernando Alonso, F1, foci.
  
Az Action naponta ellenőrzi a 06:00 és 14:00 Europe/Budapest kiadási időpontokat (CET/CEST váltás figyelembe vételével), a rövid kivonatokat és az archív JSON kiadásokat a `data/` könyvtárba menti. A GitHub Free Pages nyilvános repót igényel.
